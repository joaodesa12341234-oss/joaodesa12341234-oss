# Modelo do perfil com o Codorna Card

Este repositório é um **modelo**. Ele cria o seu perfil do GitHub já com o Codorna Card.

1. Clique em **Use this template** → **Create a new repository**.
2. Em **Repository name**, escreva o **seu usuário do GitHub**, igual. Deixe **Public**.
3. Clique em **Create repository**.
4. No repositório novo, abra **Actions** → **Codorna Card** → **Run workflow**.

Em menos de um minuto, o card aparece no seu perfil. Depois ele se atualiza sozinho todo dia.

Você pode apagar este arquivo e editar o README como quiser: só mantenha a linha do card.
